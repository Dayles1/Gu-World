# GU World — дизайн (передача в Claude Code)

Исходники макетов с холста Claude Design. Положи эту папку в репозиторий игры как `Design/` и попроси Claude Code реализовывать по ней.

Живой холст (с кликабельными экранами): https://claude.ai/artifact/KFmgcWWg9YR252VDta2g7s

## Что где

Каждый `*.dc.html` — один макет. Это HTML + inline-стили + небольшой JS-класс (`renderVals()`), в котором лежат данные и цвета. Открыть в браузере сам по себе файл нельзя (нужен рантайм холста), но **читать его как спецификацию можно**: все размеры, цвета, шрифты и тексты — прямо в разметке.

| Файл | Что это |
|---|---|
| `project/Main.dc.html` | UI-система: кнопки-пластины (все состояния), поля, переключатели, шкалы, валюта, ячейки по рангам, подсказка Гу |
| `project/Inventory.dc.html` | Инвентарь: снаряжение, сумка 8×5, фильтры, описание предмета |
| `project/HUD.dc.html` | HUD для ПК: портрет с кольцом эссенции, жизнь, миникарта-ромб, задание, чат, панель 1–9 |
| `project/MainMenu.dc.html` | Главное меню |
| `project/Character.dc.html` | Апертура: море эссенции, кольцо из 8 ячеек Гу, пути, кормление |
| `project/Shop.dc.html` | Лавка торговца: купить/продать, список товаров, сделка |
| `project/Hero.dc.html`, `project/Piece-xs48.dc.html` | Лист ракурсов героя и «Герой 2.0» (арт-направление, палитра cel-shading, сцена «сейчас/цель») |
| `project/Houses.dc.html` | 3 клана × 13 зданий + промпты для генератора арта |
| `project/Interiors.dc.html` | 3 клана × 4 интерьера с мебелью + промпты |
| `project/Clothes.dc.html` | 3 клана × 19 образов + промпты |
| `project/canvas.json` | Индекс холста: страницы, размеры артбордов |

## Дизайн-токены интерфейса

Игра строит меню кодом на uGUI (`Assets/GuWorld/Scripts/UI/UiKit.cs`). Эти токены стоит завести там как константы.

| Токен | Hex | Где |
|---|---|---|
| ink | `#0B0A0A` | фон экранов |
| panel | `#121010` / `#17130F→#0F0D0B` | панели |
| line | `#3A3128`, `#4A3E2E` | рамки |
| text | `#E6DCC8` | основной текст |
| muted | `#A69A86` | подписи |
| gold | `#C9A563` (hover `#F0D08A`) | ободки, уголки, активные вкладки |
| cinnabar | `#9C2A23` (hover `#B3342B`, pressed `#7A211B`) | главная кнопка |
| seal | `#A82E25` | квадратные печати с иероглифом |
| danger | `#C2413A` | опасные действия |
| essence | `#4E9A86` / `#8FD0BC` | первобытная эссенция |
| hunger | `#E0A13A` | Гу голоден |

Ранги (цвет эссенции и рамки ячеек): 1 `#4E9A86` зелёная медь · 2 `#C2524A` красная сталь · 3 `#C9CCD1` белое серебро · 4 `#D4AE52` жёлтое золото · 5 `#9C7AD6` пурпурный кристалл.

Шрифты: заголовки — Oranienbaum, текст — IBM Plex Sans Condensed, иероглифы на печатях — Ma Shan Zheng (все — Google Fonts, OFL).

Формы:
- главная/вторичная кнопка — вытянутый шестиугольник (`clip-path: polygon(18px 0, calc(100% - 18px) 0, 100% 50%, …)`), внутри обод 1–2 px;
- иконки-кнопки — шестиугольник;
- ячейки предметов — восьмиугольник со срезанными углами 9–10 px;
- уголки панелей — золотой завиток 40×40 (путь в разметке).

## Кланы (арка 1)

- **Гу Юэ** — индиго `#1F2A44`, серебро `#C9D2DC`, полумесяц; крыши с загнутыми карнизами, круглые проходы.
- **Бай** — белый `#E2E0DA`, лёд `#4E9CB8`/`#8FD3E8`, кристалл инея; побелённые стены, прямые крыши под снегом.
- **Сюн** — кожа `#5E3E26`, охра `#B5482E`, бронза `#A8843E`, три когтя; брёвна, солома, черепа и рога.

Под каждым зданием, интерьером и образом есть английский промпт для генератора картинок (Midjourney и т. п.).
